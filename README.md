# GitHub Essentials Lab

Hands-on practice repository covering core Git and GitHub workflows including repositories, branches, commits, and pull requests.

## Overview

This repository contains practical exercises and notes designed to build foundational version control and collaboration skills using Git and GitHub.

## Key Concepts Covered

* **Repository Management:** Initializing, cloning, and configuring repositories.
* **Core Git Workflow:** Staging (`git add`), committing (`git commit`), and syncing changes (`git push` / `git pull`).
* **Branching & Merging:** Creating feature branches, switching contexts, and resolving merge conflicts.
* **GitHub Collaboration:** Opening Pull Requests (PRs), reviewing code, and managing issues.
* **Markdown Basics:** Formatting documentation using clean Markdown syntax.

## Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com<your-username>/<repo-name>.git
   ```
2. **Navigate into the project directory:**
   ```bash
   cd <repo-name>
   ```
3. **Create a new branch for your changes:**
   ```bash
   git checkout -b practice-branch
   ```
